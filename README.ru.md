# Urban Mobility Lakehouse

Учебный проект аналитической платформы на данных городских поездок. Цель — построить Lakehouse на базе Apache Spark, Apache Iceberg и S3-совместимого объектного хранилища, предоставив SQL-доступ к таблицам через Trino.

Источник для будущей загрузки — [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page): записи поездок такси и справочник зон.

## Планируемая архитектура

| Компонент | Назначение |
| --- | --- |
| Python | Загрузка исходных файлов и регистрация запусков |
| MinIO | Хранение исходников, файлов данных и метаданных Iceberg |
| PostgreSQL | JDBC-каталог Iceberg |
| Apache Spark / PySpark | Проверка, преобразование и запись данных |
| Apache Iceberg | Управление аналитическими таблицами и snapshots |
| Trino | SQL-доступ к Iceberg-таблицам |
| Apache Airflow | Оркестрация загрузок и преобразований |

Планируемые слои: исходные файлы (Raw), нормализованные таблицы (Silver), аналитические витрины (Gold). Отдельно будут сохраняться записи с нарушениями правил качества.
